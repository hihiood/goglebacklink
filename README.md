# 구글 백링크 마스터

내 링크를 수백 개의 게시판에 자동으로 노출시키는 백링크 프로그램의 **데스크톱 버전**입니다.

## 다운로드

최신 프로그램은 [**Releases**](../../releases/latest) 페이지에서 받으세요.

- 파일: `GoogleBacklinkMaster.exe` (단일 실행 파일)
- 실행: 내려받은 `GoogleBacklinkMaster.exe` 를 더블클릭하면 바로 실행됩니다.

## 사용 설명서

[**사용 설명서 보기**](https://hihiood.github.io/goglebacklink/) — 로그인부터 발행, 결과 확인까지 실제 화면으로 안내합니다.
(GitHub Pages 가 아직 켜지지 않았다면 저장소의 `index.html` 을 브라우저로 열어 확인하세요.)

## 시스템 요구사항

- Windows 10 / 11 (64bit)
- Microsoft Edge WebView2 런타임 — Windows 11 에는 기본 내장. Windows 10 구버전은 없을 수 있으며, 없으면 실행 시 설치 안내가 표시됩니다.
- 인터넷 연결

## 설치 시 보안 경고

처음 배포되는 프로그램이라 Windows SmartScreen 이 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
**추가 정보 → 실행** 을 눌러 진행하면 됩니다. 안전한 프로그램입니다.

## 문의

프로그램 안 **문의하기**, 또는 카카오톡 · 텔레그램으로 직접 상담하실 수 있습니다.
